# MyCoach

Minimalist personal fitness PWA prototype.

## Deploy
GitHub repository: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.

## Install on iPhone
Open `https://vishakhavasu-lgtm.github.io/mycoach/` in Safari → Share → Add to Home Screen → enable Open as Web App.

## Notes
Static PWA prototype. Workout, food, profile and progress data are saved locally in this browser. WHOOP OAuth, Flo sync, AI food photo recognition, push notifications, and cloud sync are not connected yet. Do not store API keys or sensitive health information in this public repository.
